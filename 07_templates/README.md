# 07 · Templates

Plantillas reutilizables para arrancar proyectos, notebooks, informes y decisiones
de forma consistente.

| Plantilla | Uso |
|---|---|
| `template_proyecto_data.md` | Estructura y plan de un proyecto |
| `template_notebook.ipynb` | Notebook base |
| `template_readme_proyecto.md` | README de proyecto |
| `template_metodologia.md` | Documentar metodología |
| `template_diccionario_datos.md` | Diccionario de datos |
| `template_data_quality_report.md` | Informe de calidad |
| `template_articulo_datastory.md` | Artículo de data storytelling |
| `template_ADR.md` | Architecture Decision Record |

Copia la plantilla, renómbrala y rellénala. Mantén la consistencia con la metodología
de `00_documentacion/`.
