# Estructura de un artículo de data storytelling

Cómo convertir un análisis en una historia rigurosa y comprensible. Referencia:
Datadista, El Confidencial Data, The Pudding, Our World in Data.

## Estructura narrativa

1. **Gancho / titular.** Una afirmación basada en datos que importe al lector.
2. **Contexto.** Por qué este tema es relevante ahora.
3. **Pregunta.** Qué intenta responder el artículo.
4. **Evidencia.** Datos, gráficos y mapas que construyen el argumento.
5. **Hallazgo principal.** El mensaje central, claro y memorable.
6. **Matices.** Excepciones, casos particulares, contraejemplos.
7. **Limitaciones.** Qué no se puede afirmar.
8. **Metodología.** Fuentes, cómo se calculó, cómo reproducirlo.
9. **Cierre.** Implicaciones, preguntas abiertas.

## Principios

- **Una idea por gráfico.** Cada visual responde a una micro-pregunta.
- **Del general al detalle.** Primero el patrón, luego el caso concreto.
- **Honestidad estadística.** Ejes desde cero cuando toca, no cherry-picking.
- **Cita la fuente** siempre, con fecha de consulta.
- **Accesibilidad:** colores aptos para daltonismo, alt-text, lenguaje claro.

## Checklist de publicación

- [ ] Titular soportado por los datos
- [ ] Cada gráfico tiene fuente y unidades
- [ ] Metodología reproducible enlazada
- [ ] Limitaciones declaradas
- [ ] Revisión de sesgos
