## Datasets etiquetados para computer vision (teledetección)

| Dataset | Uso | Nivel |
|---|---|---|
| EuroSAT | Clasificación land cover (Sentinel-2) | Inicial |
| BigEarthNet | Clasificación multietiqueta | Intermedio |
| SEN12MS | SAR + óptico, segmentación | Intermedio/avanzado |
| xBD / xView2 | Detección de daños pre/post desastre | Avanzado |
| SpaceNet | Edificios y carreteras | Avanzado |
| QuakeSet | Terremotos con Sentinel-1 (SAR) | Avanzado |
