# Geoespacial y satélite

Análisis territorial y teledetección.

## Stack del laboratorio (open source)

GeoPandas, PostGIS, Shapely, rasterio, rioxarray, xarray, H3, Kepler.gl, QGIS, pystac-client.

## Equivalencias enterprise/cloud

BigQuery GIS, Databricks Mosaic, CARTO, Sentinel Hub, Google Earth Engine.

## Notas

- Núcleo del laboratorio. Ver `04_procesos_data` y proyectos de satélite.

## Filosofía

Open source first. Cloud when it adds value. Se elige la herramienta adecuada al
caso, no la más grande por defecto.
