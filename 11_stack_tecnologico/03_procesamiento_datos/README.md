# Procesamiento de datos

Limpiar y transformar datos a escala de una máquina.

## Stack del laboratorio (open source)

Polars, Pandas, DuckDB, NumPy.

## Equivalencias enterprise/cloud

Spark, Databricks, BigQuery, Dataflow.

## Notas

- Polars/DuckDB cubren la mayoría de casos sin cluster.

## Filosofía

Open source first. Cloud when it adds value. Se elige la herramienta adecuada al
caso, no la más grande por defecto.
