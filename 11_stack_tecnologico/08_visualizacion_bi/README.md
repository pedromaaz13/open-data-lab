# Visualización y BI

Dashboards y exploración de datos.

## Stack del laboratorio (open source)

Apache Superset, Metabase, Streamlit, Plotly, Altair, Quarto.

## Equivalencias enterprise/cloud

Looker, Power BI, Tableau, Sigma.

## Notas

- Superset/Metabase self-hosted; Streamlit para apps a medida.

## Filosofía

Open source first. Cloud when it adds value. Se elige la herramienta adecuada al
caso, no la más grande por defecto.
