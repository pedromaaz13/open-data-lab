# Data lake / lakehouse

Almacenar datos crudos y curados a escala con formatos abiertos.

## Stack del laboratorio (open source)

Parquet/GeoParquet sobre MinIO/S3; formatos Iceberg/Delta (lectura con DuckDB).

## Equivalencias enterprise/cloud

Delta Lake, Apache Iceberg, BigLake, Databricks Lakehouse.

## Notas

- Parquet + MinIO ofrece un lake ligero y portable.

## Filosofía

Open source first. Cloud when it adds value. Se elige la herramienta adecuada al
caso, no la más grande por defecto.
