# Orquestación

Programar y coordinar pipelines con dependencias y trazabilidad.

## Stack del laboratorio (open source)

Dagster (preferido), GitHub Actions, cron.

## Equivalencias enterprise/cloud

Airflow, Cloud Composer, Azure Data Factory, Dagster Cloud.

## Notas

- Dagster por sus assets y lineage. Airflow solo si ya existe en la organización.

## Filosofía

Open source first. Cloud when it adds value. Se elige la herramienta adecuada al
caso, no la más grande por defecto.
