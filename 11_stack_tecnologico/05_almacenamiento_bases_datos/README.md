# Almacenamiento y bases de datos

Persistir datos para análisis y aplicaciones.

## Stack del laboratorio (open source)

DuckDB (analítica), PostgreSQL/PostGIS (relacional/geo), SQLite, MinIO (objeto).

## Equivalencias enterprise/cloud

BigQuery, Snowflake, Cloud SQL, RDS, Supabase, Neon, MotherDuck.

## Notas

- DuckDB para analítica local; Postgres para persistencia y apps.

## Filosofía

Open source first. Cloud when it adds value. Se elige la herramienta adecuada al
caso, no la más grande por defecto.
