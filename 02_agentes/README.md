# 02 · Agentes

Prompts/agentes profesionales reutilizables, uno por fase del trabajo de datos.
Cada archivo contiene un *system prompt* listo para copiar en tu herramienta de IA,
con variables `{...}` que rellenas según el caso.

## Cómo usarlos

1. Identifica la fase del proyecto (extracción, limpieza, análisis, etc.).
2. Abre el agente correspondiente.
3. Copia el *System prompt* y rellena las variables.
4. Itera: el agente acelera el trabajo, no sustituye tu criterio.

## Principio

Los agentes siguen la misma filosofía del laboratorio: rigor, reproducibilidad,
trazabilidad y honestidad. Aceleran fases concretas; las decisiones siguen siendo tuyas.
