# Apps Streamlit

Apps de datos en Python puro. Ver `04_procesos_data/06_visualizacion/streamlit.md`.

## Ejecutar

```bash
streamlit run app.py
```

## Buenas prácticas

- Cachea cargas pesadas con `st.cache_data`.
- Separa la lógica (`src/`) de la UI.
- Despliega en Streamlit Community Cloud, Render o Fly.io.

## Ideas

- Explorador de vivienda y salarios.
- Buscador de datasets del catálogo.
- Dashboard de subvenciones.
