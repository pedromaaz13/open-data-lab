Aplicaciones y productos de datos: dashboards, APIs, apps interactivas y mapas.

| Carpeta | Tecnología | Uso |
|---|---|---|

despliegue gestionado (Render/Fly.io/Streamlit Cloud) solo cuando aporte valor.
