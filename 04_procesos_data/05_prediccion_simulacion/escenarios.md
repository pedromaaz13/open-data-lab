# Análisis de escenarios

Explorar futuros alternativos (optimista/base/pesimista) variando supuestos.

## Enfoque

- Define supuestos clave (crecimiento de precios, tipos).
- Construye 2-4 escenarios coherentes.
- Compara resultados.

## Buenas prácticas

- Documenta los supuestos de cada escenario.
- No confundas escenario con predicción.
- Combina con Monte Carlo para incertidumbre.
