# 04 · Procesos data

El corazón metodológico del laboratorio: las **fases técnicas** de un proyecto de
datos, cada una con su carpeta y documentación.

```txt
01_extraccion        →  obtener los datos (APIs, ficheros, scraping, satélite)
02_transformacion    →  limpiar, normalizar, validar
03_modelado          →  modelo dimensional y capa semántica
04_analisis          →  exploración, correlaciones, índices, anomalías
05_prediccion_simulacion → forecasting, Monte Carlo, ML
06_visualizacion     →  gráficos, mapas, dashboards, storytelling
```

Cada subcarpeta tiene un README índice y fichas temáticas con conceptos, código y
buenas prácticas. Estos procesos son agnósticos del proyecto: se reutilizan en
`06_proyectos/`.
