# Quarto

Publicación reproducible: informes, artículos y webs desde notebooks/Markdown.

## Qué ofrece

- Documentos HTML/PDF/Word desde `.qmd`.
- Código + narrativa + figuras en un solo flujo.
- Webs y blogs reproducibles.

## Ejemplo

```bash
quarto render reports/articulo.qmd --to html
```

## Buenas prácticas

- Ideal para los artículos de data storytelling.
- Versiona el `.qmd`, no solo el HTML.
- Parametriza para reutilizar.
