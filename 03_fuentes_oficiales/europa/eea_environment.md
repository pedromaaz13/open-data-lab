# EEA · Agencia Europea de Medio Ambiente

## Qué datos ofrece

Datos e indicadores medioambientales europeos: aire, agua, clima, biodiversidad.

## Temas principales

- Calidad del aire.
- Emisiones y clima.
- Uso del suelo (CORINE).

## Formatos disponibles

CSV, GeoPackage, WMS/WFS.

## API o sistema de descarga

Portales de descarga y servicios OGC; API de calidad del aire.

## Ejemplos de datasets útiles

- CORINE Land Cover.
- Calidad del aire por estación.

## Ideas de proyectos

- Cambios de uso del suelo.
- Exposición a contaminación.

## Limitaciones

Resolución variable; armonización entre países.
