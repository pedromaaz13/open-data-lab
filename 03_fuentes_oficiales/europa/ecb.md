# ECB · Banco Central Europeo

## Qué datos ofrece

Estadísticas monetarias y financieras de la eurozona.

## Temas principales

- Tipos de interés.
- Agregados monetarios.
- Tipos de cambio.

## Formatos disponibles

CSV, SDMX, JSON.

## API o sistema de descarga

ECB Data Portal / SDMX API.

## Ejemplos de datasets útiles

- Tipos de interés de referencia.
- Tipos de cambio diarios.

## Ideas de proyectos

- Contexto macro para análisis de vivienda y crédito.

## Limitaciones

Datos agregados de eurozona.

## Enlaces importantes

- https://data.ecb.europa.eu
