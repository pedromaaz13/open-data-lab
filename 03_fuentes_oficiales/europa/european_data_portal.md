# data.europa.eu · Portal de datos abiertos de la UE

## Qué datos ofrece

Catálogo federado de datos abiertos de instituciones y países de la UE.

## Temas principales

- Multisectorial; agregador europeo.

## Formatos disponibles

Diversos (CSV, JSON, RDF, GeoJSON).

## API o sistema de descarga

API DCAT-AP; SPARQL endpoint.

## Ejemplos de datasets útiles

- Datasets de movilidad y medioambiente europeos.

## Ideas de proyectos

- Búsqueda transfronteriza de datasets comparables.

## Limitaciones

Heterogeneidad de calidad y formatos.

## Enlaces importantes

- https://data.europa.eu
