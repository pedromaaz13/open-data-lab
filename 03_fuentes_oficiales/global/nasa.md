# NASA · Earth Data

## Qué datos ofrece

Datos de observación de la Tierra: clima, atmósfera, vegetación, fuegos, temperatura.

## Temas principales

- MODIS/VIIRS (vegetación, fuegos).
- Temperatura y clima (GISS).
- Precipitación (GPM).

## Formatos disponibles

HDF, NetCDF, GeoTIFF, COG; STAC.

## API o sistema de descarga

Earthdata, CMR API, FIRMS (fuegos), AppEEARS.

## Ejemplos de datasets útiles

- FIRMS: focos de incendio casi en tiempo real.
- MODIS NDVI.

## Ideas de proyectos

- Detección de incendios global.
- Anomalías de vegetación.

## Limitaciones

Registro Earthdata requerido; volumen alto.
