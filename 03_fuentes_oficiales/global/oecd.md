# OECD · OCDE

## Qué datos ofrece

Estadísticas comparadas de países desarrollados: economía, empleo, vivienda, bienestar.

## Temas principales

- Vivienda asequible.
- Mercado laboral.
- Bienestar (Better Life).

## Formatos disponibles

CSV, SDMX, JSON.

## API o sistema de descarga

OECD Data API (SDMX-JSON).

## Ejemplos de datasets útiles

- Affordable Housing Database.
- Indicadores Better Life.

## Ideas de proyectos

- Benchmark internacional de vivienda y bienestar.

## Limitaciones

Cobertura centrada en países OCDE.

## Enlaces importantes

- https://data.oecd.org
