# UN Data · Naciones Unidas

## Qué datos ofrece

Datos globales de agencias ONU: población, ODS, desarrollo, género.

## Temas principales

- Objetivos de Desarrollo Sostenible (SDG).
- Población mundial (UN DESA).

## Formatos disponibles

CSV, API, XLSX.

## API o sistema de descarga

SDG API; portales por agencia.

## Ejemplos de datasets útiles

- Indicadores ODS por país.
- Proyecciones de población.

## Ideas de proyectos

- Seguimiento de ODS.
- Contexto demográfico global.

## Limitaciones

Heterogeneidad entre agencias; calidad variable por país.

## Enlaces importantes

- https://data.un.org
- https://unstats.un.org/sdgs
