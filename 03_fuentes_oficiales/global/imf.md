# IMF · Fondo Monetario Internacional

## Qué datos ofrece

Estadísticas macroeconómicas y financieras globales.

## Temas principales

- World Economic Outlook.
- Balanza de pagos.
- Deuda pública.

## Formatos disponibles

CSV, SDMX, JSON.

## API o sistema de descarga

IMF Data API (SDMX).

## Ejemplos de datasets útiles

- Proyecciones de crecimiento (WEO).
- Deuda pública por país.

## Ideas de proyectos

- Contexto macro para análisis económicos.

## Limitaciones

Nivel nacional; algunas series con embargo temporal.

## Enlaces importantes

- https://www.imf.org/en/Data
