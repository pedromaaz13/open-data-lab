# World Bank · Banco Mundial

## Qué datos ofrece

Indicadores de desarrollo de casi todos los países: economía, pobreza, salud, educación, clima.

## Temas principales

- World Development Indicators.
- Pobreza y desigualdad.
- Clima y energía.

## Formatos disponibles

JSON, CSV, XML.

## API o sistema de descarga

API REST y cliente Python `wbgapi`.

## Ejemplos de datasets útiles

- PIB per cápita por país.
- Índice de Gini.

## Ideas de proyectos

- Comparativa internacional de desigualdad.
- Contexto global de indicadores.

## Limitaciones

Datos nacionales (poco detalle subnacional); huecos en países pequeños.

## Enlaces importantes

- https://data.worldbank.org
- https://pypi.org/project/wbgapi/
