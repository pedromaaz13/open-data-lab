# NOAA · National Oceanic and Atmospheric Administration

## Qué datos ofrece

Datos meteorológicos, climáticos y oceánicos globales.

## Temas principales

- Clima histórico (GHCN).
- Océanos y temperatura del mar.
- Eventos extremos.

## Formatos disponibles

CSV, NetCDF, API.

## API o sistema de descarga

NOAA Climate Data Online (CDO) API.

## Ejemplos de datasets útiles

- Series climáticas globales (GHCN-Daily).
- Índices climáticos (ENSO).

## Ideas de proyectos

- Tendencias climáticas de largo plazo.
- Contexto global de temperatura.

## Limitaciones

Requiere token para la API; cobertura desigual histórica.

## Enlaces importantes

- https://www.ncei.noaa.gov
- https://www.ncdc.noaa.gov/cdo-web/
