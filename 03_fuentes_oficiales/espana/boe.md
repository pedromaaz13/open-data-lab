# BOE · Boletín Oficial del Estado

## Qué datos ofrece

Legislación, anuncios, subvenciones, nombramientos y disposiciones oficiales.

## Temas principales

- Legislación y normativa.
- Anuncios y convocatorias.

## Formatos disponibles

XML, PDF, API (datos abiertos del BOE).

## API o sistema de descarga

API REST de datos abiertos del BOE; descarga de sumarios y disposiciones.

## Ejemplos de datasets útiles

- Convocatorias de subvenciones publicadas.
- Texto normativo estructurado.

## Ideas de proyectos

- Minería de texto sobre normativa.
- Seguimiento de convocatorias.

## Limitaciones

Volumen de texto; NLP necesario para análisis a escala.
