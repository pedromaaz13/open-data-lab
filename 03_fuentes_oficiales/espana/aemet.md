# AEMET · Agencia Estatal de Meteorología

## Qué datos ofrece

Datos meteorológicos y climáticos: temperaturas, precipitación, predicción, avisos.

## Temas principales

- Observación meteorológica.
- Climatología histórica.
- Predicción y avisos.

## Formatos disponibles

JSON, CSV (vía API), PDF.

## API o sistema de descarga

AEMET OpenData API (requiere API key gratuita).

## Ejemplos de datasets útiles

- Series climatológicas diarias por estación.
- Valores extremos de temperatura.

## Ideas de proyectos

- Calor extremo y desigualdad.
- Tendencias de temperatura por provincia.

## Limitaciones

Requiere API key; límites de uso; cobertura por estaciones (no malla continua).
