# INE · Instituto Nacional de Estadística

## Qué datos ofrece

Estadística oficial de España: población, vivienda, empleo, salarios, precios (IPC), economía, demografía.

## Temas principales

- Demografía y población (padrón, censos).
- Mercado laboral (EPA) y salarios.
- Precios (IPC) e índices de vivienda.
- Cuentas económicas y territoriales.

## Formatos disponibles

CSV, JSON, JSON-stat, XLSX, PC-Axis (PX).

## API o sistema de descarga

API JSON oficial (INEbase / Tempus3) y descargas directas. Consulta por tabla/serie.

## Ejemplos de datasets útiles

- Índice de Precios de Vivienda (IPV).
- Encuesta de Población Activa (EPA).
- Padrón municipal por municipio.
- Indicadores urbanos.

## Ideas de proyectos

- Ratio precio vivienda / salario por provincia.
- Evolución demográfica y despoblación.
- Brecha salarial territorial.

## Limitaciones

Algunas series con desfase temporal; cambios metodológicos entre años; granularidad limitada en municipios pequeños.
