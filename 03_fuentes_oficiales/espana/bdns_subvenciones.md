# BDNS · Base de Datos Nacional de Subvenciones

## Qué datos ofrece

Convocatorias y concesiones de subvenciones y ayudas públicas en España.

## Temas principales

- Subvenciones por organismo, beneficiario, importe y finalidad.

## Formatos disponibles

CSV, JSON (vía API/portal), Excel.

## API o sistema de descarga

Portal BDNS con API y descargas; SNPSAP.

## Ejemplos de datasets útiles

- Concesiones por comunidad autónoma y sector.
- Mayores beneficiarios de ayudas.

## Ideas de proyectos

- Mapa de subvenciones públicas.
- Análisis de concentración de ayudas.

## Limitaciones

Cobertura temporal limitada en algunos tramos; normalización de beneficiarios necesaria.
