# MITECO · Ministerio para la Transición Ecológica

## Qué datos ofrece

Datos de medioambiente, agua, energía, clima, biodiversidad y residuos.

## Temas principales

- Agua y embalses.
- Calidad del aire y emisiones.
- Energía y clima.
- Biodiversidad.

## Formatos disponibles

CSV, XLSX, WMS/WFS, PDF.

## API o sistema de descarga

Geoportales y descargas; servicios OGC (WMS/WFS) para capas.

## Ejemplos de datasets útiles

- Estado de los embalses (boletín hidrológico).
- Inventario de emisiones.

## Ideas de proyectos

- Seguimiento de sequía por cuenca.
- Relación clima-territorio.

## Limitaciones

Datos repartidos entre organismos (CHs, AEMET); formatos heterogéneos.
