# datos.gob.es · Portal de datos abiertos del Gobierno

## Qué datos ofrece

Catálogo federado de datos abiertos de administraciones públicas españolas (estatal, autonómico, local).

## Temas principales

- Multisectorial: economía, medioambiente, transporte, sociedad.
- Agregador de catálogos de CCAA y ayuntamientos.

## Formatos disponibles

CSV, JSON, XML, GeoJSON, según el publicador.

## API o sistema de descarga

API basada en DCAT-AP; búsqueda y descarga de metadatos y recursos.

## Ejemplos de datasets útiles

- Datasets municipales de movilidad.
- Presupuestos abiertos.
- Datos medioambientales autonómicos.

## Ideas de proyectos

- Buscador unificado de datasets para el laboratorio.
- Comparativa de apertura de datos entre CCAA.

## Limitaciones

Calidad y frecuencia heterogéneas según publicador; enlaces a veces rotos.
