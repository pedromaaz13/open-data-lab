# 03 · Fuentes oficiales

Catálogo de organismos, portales y APIs de datos abiertos, organizados por ámbito:
España, Europa y global. Cada ficha sigue la misma plantilla para poder comparar
fuentes con rapidez.

## Plantilla de cada fuente

```md
# Nombre del organismo
## Qué datos ofrece
## Temas principales
## Formatos disponibles
## API o sistema de descarga
## Ejemplos de datasets útiles
## Ideas de proyectos
## Limitaciones
## Enlaces importantes
```

## Estructura

```txt
03_fuentes_oficiales/
├── espana/   Organismos y portales españoles
├── europa/   Instituciones y agencias de la UE
├── global/   Organismos internacionales
└── datasets_interesantes.md   Selección curada de datasets concretos
```

## Cómo usar este catálogo

1. Identifica el dominio de tu pregunta (vivienda, clima, gasto público...).
2. Busca el organismo en el ámbito correspondiente.
3. Registra la fuente que uses en `09_data_catalog/catalogo_organismos.csv` y
   `catalogo_datasets.csv`.
4. Documenta la trazabilidad (ver `00_documentacion/trazabilidad_fuentes.md`).
