# 05 · Notebooks

Notebooks de análisis organizados por temática. Son el espacio para **explorar y
narrar**; la lógica reutilizable vive en `src/` de cada proyecto.

## Temáticas

| Carpeta | Tema |
|---|---|
| `vivienda/` | Precios, alquiler, esfuerzo de acceso |
| `coste_vida/` | IPC, inflación, poder adquisitivo |
| `clima_medioambiente/` | Temperatura, agua, calidad del aire |
| `copernicus_satelite/` | NDVI, incendios, teledetección |
| `contratacion_subvenciones/` | Gasto público, anomalías |
| `geoespacial_kepler/` | Mapas y análisis territorial |
| `memoria_publica/` | Datos históricos y memoria social |

## Convenciones

- Nombra los notebooks `NN_descripcion.ipynb` (orden de ejecución).
- Deben correr con *Restart & Run All*.
- Limpia outputs antes de commitear (o usa `jupytext`/`nbstripout`).
- Ver `00_documentacion/buenas_practicas_notebooks.md`.
