# Roadmap

Hoja de ruta del Open Data Lab. Las fases son incrementales: cada una añade
capacidades sin romper lo anterior.

## Fase 1 - Estructura base

- Crear repositorio
- Documentar metodología
- Crear catálogo de fuentes
- Crear agentes base
- Crear templates
- Crear stack tecnológico base

## Fase 2 - Primeros notebooks

- Reproducir ejemplo Kepler.gl
- Crear notebook de vivienda y salarios
- Crear notebook de calor extremo
- Crear notebook de subvenciones públicas

## Fase 3 - Stack pro open source

- Añadir Docker Compose
- Configurar DuckDB
- Configurar PostgreSQL/PostGIS
- Configurar dbt Core
- Crear primeros modelos
- Añadir tests de calidad

## Fase 4 - Visualización avanzada

- Exportar mapas Kepler.gl
- Crear dashboard Streamlit
- Crear dashboards en Superset/Metabase
- Crear artículos tipo data storytelling

## Fase 5 - Ciencia de datos

- Forecasting de vivienda
- Índices compuestos de vulnerabilidad
- Clustering de municipios
- Detección de anomalías en contratos
- Simulaciones Monte Carlo

## Fase 6 - Producto

- Crear API con FastAPI
- Crear app pública
- Crear buscador de datasets
- Crear agente conversacional sobre los datos
- Publicar portfolio

## Fase 7 - Cloud opcional

- Evaluar Supabase/Neon
- Evaluar MotherDuck
- Evaluar Render/Vercel
- Evaluar BigQuery/Databricks solo si el caso lo justifica
